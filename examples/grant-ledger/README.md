# Grant Ledger

An offline tracker for a small nonprofit's grant applications.
It should help staff see upcoming deadlines and prepare a spreadsheet for meetings.

## Setup

Use Python 3.11 or newer. No external packages are required.
Start the tracker with `python main.py`.

## Current state

The command-line view lists saved applications and requested amounts.
CSV export is the next feature to finish. Keep the first version local and simple.
An edit screen and reminder emails are longer-term ideas, not implemented features.
